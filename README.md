# LittleBloom Demo v0.1

Owner/director-facing daycare dashboard with fictional sample data. This is a presentation demo; buttons and records are simulated.

## Run locally

```bash
npm ci
npm start
```

## GitHub Pages

In repository **Settings → Pages → Build and deployment**, set **Source** to **GitHub Actions**. A push to `main` deploys the site at https://archercopiers.github.io/littlebloom-demo/ .
